### Sophia — private full-stack product

Sophia is a philosophy reading companion centered on focused reading, reflection, and private annotations. I am building it with React, TypeScript, Express, PostgreSQL, and Prisma, including user-owned libraries, protected PDF access and processing, reading progress, highlights, and notes.

The system preserves the original PDF for reading while separately deriving pages, chapters, and chunks. That structure is the foundation for contextual AI work still in development; it is not presented as a completed AI product. The source repository is private.

I contributed under the guidance of a senior AI/ML engineer to a team project created for the Google DeepMind Gemma 3n Hackathon. My work touched model and dataset experimentation, fine-tuning and LoRA research, evaluation and integration, and the React Native product and on-device deployment constraints for multilingual Tamazight translation.

[Team repository](https://github.com/mindful-ai-dude/v3.6-Tamazight_MultiLingo_App) · [Models and datasets](https://huggingface.co/tamazightdev)

### DiffShow — open-source developer tooling

DiffShow is an offline TypeScript CLI I built to turn local Git changes or differences between refs into self-contained HTML or Markdown review reports. It includes changed-file navigation, before-and-after views, line numbers, unified patches, binary metadata, responsive and accessible controls, and light/dark support—without accounts, telemetry, or source-code uploads.

[View the source](https://github.com/ziyad455/diffshow) · [Install from npm](https://www.npmjs.com/package/diffshow)
