### DiffShow

**Open-source Git review CLI**

DiffShow transforms local Git changes or differences between branches into polished, self-contained HTML reports.

**Stack:** Node.js · TypeScript · Git · HTML · CSS

**Highlights:**

- Generates portable before-and-after reports.
- Supports working-tree and branch comparisons.
- Displays file navigation, statuses, line totals, and patches.
- Includes responsive layouts and accessible controls.
- Runs locally without telemetry or source-code uploads.
